# Password Generator

## 📌 Description

The Password Generator is a GUI-based Python application developed using Tkinter. It generates secure and random passwords based on the user's preferences. Users can select the password length and choose whether to include uppercase letters, lowercase letters, numbers, and special characters. The application also displays the password strength and provides an option to copy the generated password to the clipboard.



## ✨ Features

- Graphical User Interface (GUI)
- Generate strong random passwords
- User-defined password length
- Uppercase letters (A-Z)
- Lowercase letters (a-z)
- Numbers (0-9)
- Special characters
- Password strength indicator
- Copy password to clipboard
- Input validation
- Error handling



## 🛠 Technologies Used

- Python 3
- Tkinter
- Random Module
- String Module
